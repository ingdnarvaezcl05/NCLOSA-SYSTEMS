# NCLOSA Systems - Arquitectura Tecnológica 🚀

Este repositorio contiene el código fuente de la página web oficial y portafolio de **NCLOSA Systems**, una iniciativa enfocada en brindar soluciones integrales de tecnología.

## 📌 Sobre el Proyecto
La página está diseñada para transmitir una identidad corporativa, tecnológica y de alta seguridad. Funciona como la carta de presentación para servicios de desarrollo a medida, administración de redes y ciberseguridad.

## 🛠️ Tecnologías Utilizadas
*   **HTML5:** Estructura semántica.
*   **CSS3:** Diseño responsivo, variables de color (rojo/negro/blanco) y UI moderna.
*   **Vanilla JavaScript:** Lógica para la ventana modal de autenticación y renderizado del efecto "Matrix" de código binario animado en el fondo mediante HTML5 Canvas.

## ✨ Características Principales
*   **Efecto Visual de Alto Rendimiento:** Lluvia de código binario generada por JS sin necesidad de videos externos, optimizando la carga.
*   **Diseño Responsivo:** Adaptable a dispositivos móviles y escritorio.
*   **Sistema de Login:** Modal de autenticación para acceso administrativo (Interfaz frontend).
